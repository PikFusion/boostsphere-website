# 4. MOST IMPORTANT CUSTOM FEATURE — OUR APPROACH

This is the signature interaction of the website.

The content contains:

01 — Understand
02 — Research
03 — Strategise
04 — Create
05 — Execute
06 — Optimise
07 — Report

Do NOT simply display these as seven normal cards.

Create a **custom horizontal scrolling storytelling section** inspired by a journey/bus route.

## Required behavior

When the user reaches the **Our Approach** section:

1. The section becomes pinned/sticky.
2. The user's normal vertical scrolling controls the horizontal animation.
3. A visually attractive road/path appears.
4. A stylised BoostSphere bus travels along the route.
5. There are **7 stops**.
6. Each stop represents one approach step.
7. As the user scrolls:

   * Bus moves toward Stop 01
   * Step 01 becomes active
   * Bus continues toward Stop 02
   * Step 02 becomes active
   * Continue through all 7 steps
8. After Step 07 is completed, the horizontal experience ends.
9. Normal vertical scrolling resumes.

The experience should feel like:

**"Taking a brand from understanding → research → strategy → creation → execution → optimisation → reporting."**
